# Machine Translation & Attention Mechanism

Реализация и исследование архитектур Sequence-to-Sequence (RNN, Attention, Multi-Head Attention) для задачи машинного перевода имен. В банковской сфере подобные механизмы используются для анализа последовательностей транзакций, обработки клиентских обращений и детекции аномалий в потоках данных. 
Цель проекта — понять принципы работы Attention механизма и научиться проводить валидацию сложных DL-моделей, где критически важно отслеживать переобучение (data leakage) и оценивать интерпретируемость весов.


## Реализованные архитектуры
1. **RNN Encoder-Decoder (Baseline):**
   - Реализован базовый пайплайн Seq2Seq с использованием GRU/LSTM (PyTorch).
   - Внедрен механизм Early Stopping по метрике на валидационной выборке для предотвращения переобучения.
2. **Attention Mechanism:**
   - Реализован кастомный слой Attention (без использования встроенных классов фреймворка) для вычисления весов между выходами энкодера и текущим шагом декодера.
3. **Positional Encoding:**
   - Реализованы и сравнены два подхода к кодированию позиций: синусоидальный (Sine/Cosine) и обучаемый (Trainable weights).
   - Проведена визуализация выученных весов позиционного кодирования.
4. **Multi-Head Attention:**
   - Реализован механизм Multi-Head Attention (3 головы) с нуля.
   - Внедрен каузальный маскинг (Masking) для исключения утечки данных из будущего (Data Leakage) при обучении.
5. **Transformer Architecture (Bonus):**
   - Собрана полная архитектура Transformer для задачи перевода.


## Методология оценки (Validation)
Поскольку задача связана с генерацией текста, использовались как количественные, так и качественные метрики:
- **Количественный:** Оценка Perplexity на тестовой выборке, контроль сходимости функции потерь (Cross-Entropy Loss) на train/valid.
- **Анализ выравнивания (Attention Audit):** Визуализация матриц внимания. Подтверждено наличие диагонального сдвига в одной из голов (Head shift = 1), что доказывает способность модели выучивать позиционные зависимости.
- **Качественный:** Генерация переводов для 5 случайных имен из train и valid выборок каждые N эпох для визуальной оценки реалистичности.
- **Валидация метрик:** Реализация метрики BLEU для оценки качества перевода (Bonus).
